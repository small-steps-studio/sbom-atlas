# Pro reports

* **Show License Risk**: Components sorted into permissive, weak copyleft, strong copyleft and unknown licenses, with the ones to review.
* **Show NTIA Minimum Elements**: Checks the NTIA minimum elements: author, timestamp, dependency relationships, and supplier, name, version and unique identifier per component.

The first Pro command starts a free 14-day trial on this computer. After the trial, Pro is a one-time purchase: USD 19 (Personal) or USD 39 per user (Business).
